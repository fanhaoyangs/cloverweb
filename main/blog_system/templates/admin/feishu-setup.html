飞书文档导入

需要配置飞书应用

在使用飞书文档导入功能之前，需要先在飞书开放平台创建应用，并配置相关参数。

配置步骤：

  1. 访问 飞书开放平台 创建企业内部应用
  2. 在应用详情页获取 App ID 和 App Secret
  3. 配置应用权限：文档读取、用户信息读取
  4. 设置重定向URL：{{ request.host_url }}admin/feishu/callback
  5. 在系统环境变量或 .env 文件中配置： 
    FEISHU_APP_ID=your_app_id
FEISHU_APP_SECRET=your_app_secret
FEISHU_REDIRECT_URI={{ request.host_url }}admin/feishu/callback
