## 一、项目概述

### 1.1 项目背景

四叶草堂团队现计划在现有博客系统（基于Flask框架）基础上，开发一个「项目工时统计」网页应用。该应用将与飞书平台深度集成，实现员工工时的在线填报、统计和汇总管理。

### 1.2 建设目标

- 建立标准化的项目工时填报流程
- 实现与飞书多维表格的数据互通
- 通过飞书机器人实现自动化通知提醒
- 支持管理端对填报情况的监控和统计

### 1.3 建设原则

- **易用性**：界面简洁直观，操作流程顺畅
- **准确性**：数据实时同步，确保填报准确
- **及时性**：自动推送提醒，确保按时填报
- **可扩展性**：预留接口，便于后续功能扩展

## 三、功能模块设计

### 3.1 功能模块总览

| 模块名称 | 功能描述 | 用户角色 |
|----------|----------|----------|
| 工时填报 | 月度项目工时在线填报 | 普通员工 |

| 管理后台 | 员工管理、提交状态监控 | 管理员 |
| 飞书集成 | 多维表格读写、机器人通知 | 系统 |

### 3.2 工时填报模块

#### 3.2.1 月份选择与工作日设置

**功能描述**：
- 用户进入填报页面后，首先选择填报月份（默认当前月份）
- 系统自动计算该月的工作日天数（周一至周五，排除法定节假日）
- 用户可手动调整工作日天数：
  - **增加天数**：表示有加班
  - **减少天数**：表示有请假或缺勤
  - **兼职人员**：按实际工作天数填写

**界面原型**：
```
┌─────────────────────────────────────────────────────────┐
│  📅 填报月份：[2026年3月 ▼]                              │
│  工作日天数：[22.0] 天（可修改）                          │
│  提示：数字格式保留一位小数点，如 22.5 表示22天半           │
└─────────────────────────────────────────────────────────┘
```

#### 3.2.2 项目选择

**功能描述**：
- 用户从下拉菜单中选择项目名称
- 支持搜索过滤功能
- 项目列表从飞书多维表格「项目信息汇总表」的「项目名称」列获取
- 如项目不存在，提示联系管理员添加

**数据来源**：
```
飞书多维表格：项目信息汇总表
字段：项目名称
获取方式：bitable.search_records
```

**界面原型**：

#### 3.2.3 工时录入

**功能描述**：
- 用户输入该项目在本月的工作天数
- 支持两种输入方式：
  1. **直接输入天数**：输入数值如 `10.5`
  2. **输入比例**：输入百分比如 `50%`，系统自动计算天数

**计算公式**：
```
工作天数 = 总工作日天数 × 分配比例
```

**界面原型**：
```
┌─────────────────────────────────────────────────────────┐
│  项目：社区花园营造项目 - 浦东新区                        │
│                                                         │
│  ○ 直接输入天数：[10.5] 天                              │
│                                                         │
│  ○ 按比例分配：[50] %  →  计算结果：11.0 天             │
│                                                         │
│  [ 添加到工时列表 ]                                     │
└─────────────────────────────────────────────────────────┘
```

**功能描述**：

**操作流程**：
1. 管理员选择汇总月份（必选）
2. 系统查询该月所有已提交的工时记录
3. 按员工姓名分组，展示各员工的工时明细
4. 支持导出为 Excel / CSV 格式

**导出字段说明**：
| 字段 | 数据来源 | 说明 |
|------|----------|------|
| 员工姓名 | employees.name | 工时提交者的姓名 |
| 项目名称 | work_hour_items.project_name | 该员工参与的项目名称 |
| 工时分配 | work_hour_items.work_days | 该项目的工作天数（保留1位小数）|

**数据展示规则**：
- 按员工姓名字母排序，同一员工内按项目名称排序
- 仅显示已提交（status='submitted'）的记录
- 工时分配单位：天，格式如 "10.5"

## 六、数据库设计

### 6.1 数据库表结构

#### 6.1.1 员工表 (employees)

```sql
CREATE TABLE employees (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    feishu_user_id VARCHAR(64) NOT NULL UNIQUE COMMENT '飞书用户ID',
    name VARCHAR(100) NOT NULL COMMENT '员工姓名',
    email VARCHAR(255) COMMENT '邮箱',
    department VARCHAR(100) COMMENT '部门',
    is_active BOOLEAN DEFAULT 1 COMMENT '是否启用',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_feishu_user_id ON employees(feishu_user_id);
```

#### 6.1.2 工时记录表 (work_hour_records)

```sql
CREATE TABLE work_hour_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    employee_id INTEGER NOT NULL COMMENT '员工ID',
    year INTEGER NOT NULL COMMENT '年份',
    month INTEGER NOT NULL COMMENT '月份',
    total_work_days DECIMAL(4,1) NOT NULL COMMENT '工作日天数',
    status VARCHAR(20) DEFAULT 'draft' COMMENT '状态: draft/submitted',
    submitted_at DATETIME COMMENT '提交时间',
    feishu_record_id VARCHAR(100) COMMENT '飞书记录ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (employee_id) REFERENCES employees(id),
    UNIQUE KEY unique_employee_month (employee_id, year, month)
);

CREATE INDEX idx_employee_month ON work_hour_records(employee_id, year, month);
```

#### 6.1.3 工时明细表 (work_hour_items)

```sql
CREATE TABLE work_hour_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    record_id INTEGER NOT NULL COMMENT '工时记录ID',
    project_name VARCHAR(200) NOT NULL COMMENT '项目名称',
    work_days DECIMAL(4,1) NOT NULL COMMENT '工作天数',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (record_id) REFERENCES work_hour_records(id) ON DELETE CASCADE
);
```

#### 6.1.4 飞书配置表 (feishu_config)

```sql
CREATE TABLE feishu_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    config_key VARCHAR(100) NOT NULL UNIQUE COMMENT '配置键',
    config_value TEXT COMMENT '配置值',
    description VARCHAR(255) COMMENT '配置描述',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 初始化默认配置

('work_hour_table_prefix', '工时统计_', '月度工时表名前缀'),

```

## 十、定时任务设计

### 10.1 定时任务清单

| 任务名称 | 触发时间 | 功能描述 |
|----------|----------|----------|
| 月度填报通知 | 每月28日 09:00 | 向所有员工发送填报提醒 |
| 补发通知 | 每月30日 09:00 | 向未提交员工再次发送提醒 |
| 清理过期草稿 | 每月1日 03:00 | 清理上个月的草稿数据 |

### 10.2 实现方式

使用飞书开放平台的「定时触发器」实现自动化，无需在代码中安装定时任务库。

**配置步骤（飞书开放平台）**：

1. 登录飞书开放平台，进入您的应用
2. 在「开发配置」→「定时触发器」中添加触发器
3. 配置触发时间和请求参数：

| 触发器 | 触发时间 | 请求URL | 请求方法 |
|--------|----------|---------|----------|
| 月度填报通知 | 每月28日 09:00 | `https://your-domain.com/workhour/api/send-reminder` | POST |
| 补发通知 | 每月30日 09:00 | `https://your-domain.com/workhour/api/send-reminder` | POST |

4. 请求Body参数：
```json
{
  "type": "monthly_reminder"  // 或 "reminder_reminder"
}
```

**后端需新增API端点**（已包含在代码中）：
```
POST /workhour/api/send-reminder
```

   ```bash
   cd /path/to/blog_system

   ```

   ```bash
   source venv/bin/activate
   pip install -r requirements.txt
   ```

   ```bash
   export FEISHU_APP_ID="your_app_id"
   export FEISHU_APP_SECRET="your_app_secret"

   ```

   ```bash
   flask init-workhour-db
   ```

   ```bash
   systemctl restart gunicorn
   systemctl restart nginx
   ```

1. 在飞书开放平台创建应用

   - `im:message` - 消息发送
